# Aa 的 Warframe 助手

把 Warframe 的常用信息带进聊天。

[![PyPI](https://img.shields.io/pypi/v/nonebot-plugin-aawarframe.svg)](https://pypi.org/project/nonebot-plugin-aawarframe/)
[![Python](https://img.shields.io/badge/Python-3.12-blue)](https://www.python.org/)
[![License](https://img.shields.io/github/license/nekox41/nonebot-plugin-aawarframe.svg)](./LICENSE)

</div>

它是一个基于 NoneBot2 的 Warframe 查询插件。你可以在 QQ 里查看游戏状态、查询交易信息、分析紫卡，也可以订阅自己关心的变化。

支持 QQ 官方机器人和 OneBot V11。查询结果会整理成图片卡片，尽量让信息一眼就能看清。

## 能做什么

- 查看世界状态、裂缝、赏金和每周轮换
- 查询 Warframe Market 挂单、成交趋势和遗物部件
- 查询紫卡价格、词条数值，并识别紫卡截图
- 订阅夜灵、裂缝、仲裁和市场等提醒
- 搜索 Warframe Wiki
