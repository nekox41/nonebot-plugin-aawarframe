# 功能介绍

命令前缀由 NoneBot 项目配置决定。下面的示例假设前缀是 `/`；如果你的机器人使用其他前缀，替换掉即可。

## 游戏状态

查看实时世界状态和各类轮换：

- `/平原`、`/突击`、`/入侵`、`/奸商`
- `/执刑官`、`/裂缝`、`/钢铁裂缝`、`/九重天`
- `/时光`、`/深层`、`/仲裁`
- `/氏族`、`/电波`、`/日历`、`/钢精`、`/回廊`、`/灵化`

## 赏金与奖励

查看不同区域的赏金、阶段奖励和任务池：

- `/赏金`、`/地球`、`/金星`、`/火卫二`
- `/圣所`、`/扎里曼`、`/1999`

部分命令可以带阶段编号，例如 `/金星 1`，查看指定阶段的奖励。

## 市场与遗物

- `/wm 膛线`：查看市场挂单
- `/趋势 膛线`：查看成交趋势
- `/部件 阿利乌双枪p`：查找装备部件对应的遗物
- `/遗物 古纪A1`：查看遗物奖励和市场价格

## 紫卡

- `/wmr 伯斯顿`：查找紫卡挂单
- `/zk`、`/zk已洗`：查看紫卡价格排行
- `/数值 伯斯顿`：查看紫卡词条数值范围
- `/词条`：查看词条名称和缩写
- 发送 `/分析` 并附上一张紫卡图片：识别词条并分析数值

图片识别需要额外安装 `[ocr]` 依赖。

## Wiki

`/wk 关键词` 可以搜索 Warframe Wiki，并返回相关条目。

## 订阅提醒

插件可以把关心的变化主动发到原来的群或频道：

```text
/订阅 夜灵
/订阅 裂缝 生存
/订阅 仲裁
/我的订阅
/取消订阅 1
```

可订阅的内容还包括赏金、阿耶、九重天和紫卡挂单等。具体条件由订阅类型决定；发送 `/帮助` 可以查看当前命令，发送 `/我的订阅` 查看自己的订阅清单。

## 帮助

发送 `/帮助` 查看当前可用命令。管理员可以在管理台中启用或停用命令，并设置用户和群组访问规则。
