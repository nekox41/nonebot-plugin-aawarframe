# 紫卡图片分析

发送“分析”并附图，或引用一张图片。只截下半张卡也可以，但需要保留武器名称和全部词条。无法唯一确定强化等级时，补充“满级”或“0级”等参数。

## 识别流程

使用 PaddleOCR，在独立进程中排队识别，最多容纳 8 个请求。模型常驻内存，不阻塞其他查询。

1. 校正图片方向，按比例缩放；限制文件和像素数量。
2. 优先识别原图。失败后围绕数值行保留武器名称和换行空间，再按文字基线纠偏，再尝试灰度局部增强。文字检测框负责局部透视校正，不依赖完整卡框。
3. 按坐标合并同一行，再将换行描述接回对应数值。锁图标不参与计算。
4. 使用现有资源匹配武器与词条，检查数量、正负号、武器类型和数值范围。不清楚时要求重新截图。

| 样例 | 处理重点 |
| --- | --- |
| 标准卡面 | 容量、段位和循环次数不能当作强化等级 |
| 长词条换行 | 合并射速说明与跨行词条 |
| 倾斜卡面 | 校正文字基线，保留原图识别结果 |
| 锁定词条 | 忽略锁图标，保留正负号和小数 |

## 数值与评级

沿用“数值”命令的系数，结合词条组合及强化等级计算均值。截图缺少强化标记时，枚举 0—8 级；仅接受唯一符合全部词条范围的等级。派系倍率先扣除基准 1；后坐力按实际增益方向判断正负。

偏差为“识别数值的绝对值 ÷ 均值的绝对值 − 1”。正面直接评级，负面反向评级，惩罚越小越好。

| 评级 | 评级偏差 |
| --- | --- |
| F | ＜−7% |
| E | −7% 至＜−4% |
| D | −4% 至＜−1% |
| C | −1% 至＜+1% |
| B | +1% 至＜+4% |
| A | +4% 至＜+7% |
| S | ≥+7% |

结果展示词条、识别数值、均值、偏差与评级。受游戏显示小数位影响，临界评级属于估算。图片只在本机处理，不上传 OCR 服务。
